# 孤影の弓 ― 模擬戦 ―

ブラウザで遊べる一人称視点のアクションゲーム（オリジナル作品）。ビルドは不要です。
舞台は **模擬戦（演習）** です。武器はすべて先端に塗料が付いた練習用で、当たると明るい橙色（#FF9A1F）の塗料の跡が残ります（血・赤色の表現はありません）。
青組のあなたは、青組の侍女たち（味方）と一緒に橙組の侍女たちを迎え撃ちます。

公開版: https://reimei292-afk.github.io/onna-kessen/

## 起動方法
- **公開版**: 上の URL をスマホまたは PC のブラウザで開く。
- **ローカルサーバ（推奨）**: このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開く。
- **ファイルを直接開く**: `index.html` を開いても遊べます（3D モデルは `assets/models.js` の埋め込みデータを使用。収録音声は使えず、ブラウザの音声合成になります）。

タイトル画面でステージ（**平原の戦い** / **櫃の戦い**）を選び、「開始」を押します。

## 操作方法（PC）
| 操作 | キー |
|---|---|
| 移動 / 走る / 跳ぶ | W A S D / Shift / Space |
| 視点 | マウス |
| 武器切替 | 1（弓矢）/ 2（懐刀）/ マウスホイール |
| 弓矢 | 左クリック長押しで引き、離して射る（右クリックで引き戻し） |
| 懐刀 | 左クリックで突き（正面・至近距離の一人だけ） |
| 梯子 | 梯子のそばで W で上る、S で下りる（Space で飛び降り） |
| 秘書課の侍女に頼む | 近くで E |
| 一時停止 | Esc |

## 操作方法（スマホ・横向き）
左側ドラッグ＝移動スティック、右側ドラッグ＝視点。ボタン：攻撃（弓は長押し→離す、懐刀はタップ）・武器切替・走る（切替式）・跳ぶ・一時停止・頼む（秘書の近くで表示）。縦向きでは「横向きにしてください」と表示され一時停止します。

## ルール
- 波ごとに **橙組と同じ人数の青組** が出ます。両軍とも弓兵が約7割、近接兵（懐刀・突きのみ）が約3割。
- 侍女は一人ずつ名前・身長（150〜175cm）・性格（好戦的／慎重／臆病／冷静／陽気）が違い、行動と台詞が変わります。照準を合わせると顔写真・名前・性格が表示されます。
- 頭上の ▼（青＝味方、橙＝敵）とレーダーの色でチームを見分けます。塗料の色はすべて橙です。
- **同士討ち**: あなたの矢と懐刀は味方にも当たります（「味方撃破」に記録）。NPC の矢は味方同士では当たりません。
- **戦死判定**: 体力が 0 になった侍女は倒れるアニメのあと、その場で静止したまま残ります（最大100人。超えると古い順に消えます）。
- 竹林・竹束・木の壁は矢を防ぎます。弓兵は竹束や胸壁の陰でしゃがみ、立ち上がって射ます。

## ステージ
- **平原の戦い**: 竹林が点在する平原。後方に本陣（陣幕）があります。
- **櫃の戦い**: 青組は丸太の砦（門つき）を守ります。二基の櫃（やぐら）と壁の内側の足場に味方の弓兵が陣取り、あなたは左の櫃の上から開始。梯子で上り下りできます。橙組は門の外から竹束を盾に波状に攻めてきます。

## 本陣と秘書課の侍女（白瀬 澄）
本陣（陣幕の内側）にいる間は安全で、敵に狙われません（戦は続きます）。秘書課の侍女（架空の人物。写真は使っていません）に頼めること：
お茶を淹れて（体力回復）／戦況を報告して（味方・敵の数と波）／作戦を相談（味方の方針を攻勢⇔守勢）／肩を揉んで（60秒間、矢の回復が2倍速）／扇であおいで（ひと休み）／矢を補充して／感想を言う（櫃の塗料・どちらの櫃が押されているか・味方の粘り・敵の弓兵の多さに、戦況に応じて答えます）／**一緒に来て**（弓兵として同行し援護。あなたの攻撃は当たりません。敵に倒されると戦死判定になり、次の波で本陣に戻ります）／**本陣に戻って**。

## 音声
- 侍女の台詞は **edge-tts（Microsoft ニューラル音声 ja-JP-NanamiNeural）** で事前に生成した mp3（`assets/voices/`、目録 `voices.js`）。性格ごとに話速・高さを控えめに変え、同じ台詞を言い方の違いで3通り用意し、再生時に ±3% の揺らぎを加えています。距離で音量が変わります。
- edge-tts で使える日本語の女性ニューラル音声は Nanami のみのため、声の個性は高さ・速さの違いで付けています。
- 再生成: `pip install edge-tts && python3 tools/make_voices.py assets/voices/lines.json`
- 音声ファイルが無い／file:// で開いた場合はブラウザの音声合成（Web Speech）を使います。

## 3D モデルとクレジット
- 侍女の体: **Quaternius「Animated Women Pack」**（CC0 / パブリックドメイン）https://quaternius.com/packs/animatedwomen.html （Poly Pizza 経由で取得）。
  2体（`assets/models/woman2.glb`, `woman3.glb`）を使い、白い上衣・黒いズボン・黒い帯・黒い靴・銀のティアラ（組頭は金）に色付け・小物追加しています。アニメ（待機・歩き・走り・突き・座り・倒れる）は AnimationMixer でクロスフェード。弓の構えは突きアニメの姿勢を流用しています。
- 両軍とも約5人に1人がメガネ（細いフレームを頭の骨に装着。黒・銀・赤茶、丸型・角型）。メガネの子は「冷静」な性格になりやすく、照準の情報欄に「メガネ」と表示されます。
- 塗料の跡と刺さった矢は、当たった位置に最も近い骨に取り付けています（スキンメッシュの変形に追従させるため、DecalGeometry ではなく骨に付けた平たい塗料の形状を使っています）。
- three.js r158（MIT）。GLTFLoader / SkeletonUtils は `lib/three-ext.min.js` に同梱（three.js の examples から作成、MIT）。
- 照準パネルの顔写真は `assets/mobNN.png` / `archerNN.png`（差し替えは `tools/make_sprites.py`）。
