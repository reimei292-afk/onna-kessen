# 孤影の弓 ― 模擬戦 ―

ブラウザで遊べる一人称視点のアクションゲーム（オリジナル作品）。ビルドは不要です。
舞台は **模擬戦（演習）** です。武器はすべて練習用（布で包んだたんぽ矢・刃引きの懐刀）です。命中時には赤いダメージ用パーティクルとヒットエフェクトが表示されます（実写の流血表現ではありません）。
青組のあなたは、青組の侍女たち（味方）と一緒に橙組の侍女たちを迎え撃ちます。

公開版: https://reimei292-afk.github.io/onna-kessen/

## 起動方法
- **公開版**: 上の URL をスマホまたは PC のブラウザで開く。
- **ローカルサーバ（推奨）**: このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開く。
- **ファイルを直接開く**: `index.html` を開いても遊べます（写真のフレームは `assets/frames/frames_data.js` の埋め込みデータを使用。収録音声は使えず、ブラウザの音声合成になります）。

タイトル画面でステージ（**平原の戦い** / **櫃の戦い** / **機内の戦い** / **城の戦い** / **浜の戦い** / **極寒の戦い** / **山城の戦い**）を選び、「開始」を押します。

## 操作方法（スマホ・横向き）
左側ドラッグ＝移動スティック、右側ドラッグ＝視点。ボタン：攻撃（弓は長押し→離す、懐刀はタップ）・武器切替・走る（切替式）・跳ぶ・一時停止・頼む（秘書の近くで表示）・**梯子**（梯子の近くで表示。押すと自動で上る／下りる）・**襖**（城の戦いで襖の近くに表示。開け閉め）・**投げる**（懐刀を持っているとき表示）・**乗る／降りる**（軽自動車の近くで表示。乗っている間は攻撃ボタンで行き先、スティック前で前へ）。縦向きでは「横向きにしてください」と表示され一時停止します。

## ルール
- 波ごとに **橙組と同じ人数の青組** が出ます。両軍とも弓兵が約7割、近接兵（懐刀・突きのみ）が約3割。
- 侍女は一人ずつ名前・身長（150〜175cm）・性格（好戦的／慎重／臆病／冷静／陽気）が違い、行動と台詞が変わります。照準を合わせると顔写真・名前・性格が表示されます。
- 頭上の ▼（青＝味方、橙＝敵）とレーダーの色でチームを見分けます。
- **同士討ち**: あなたの矢と懐刀は味方にも当たります（「味方撃破」に記録）。NPC の矢は味方同士では当たりません。
- **戦死判定**: 体力が 0 になった侍女は倒れるアニメのあと、その場で静止したまま残ります（最大100人。超えると古い順に消えます）。
- 竹林・竹束・木の壁は矢を防ぎます。弓兵は竹束や胸壁の陰でしゃがみ、立ち上がって射ます。

## ステージ
- **平原の戦い**: 竹林が点在する平原。後方に本陣（陣幕）があります。
- **櫃の戦い**: 青組は丸太の砦（門つき）を守ります。二基の櫃（やぐら）と壁の内側の足場に味方の弓兵が陣取り、あなたは左の櫃の上から開始。梯子で上り下りできます。橙組は門の外から竹束を盾に波状に攻めてきます。
- **機内の戦い**: 飛行中の旅客機の機内（曲面の壁と天井、流れる空と峡谷の見える楕円窓、手荷物棚、客室灯）。前から順に、ファーストクラスのラウンジ（殿の席・秘書課が客室乗務員のように控える）、仕切りの高い個室（スイート）、通路の狭い（約0.56m・一人幅）エコノミー、最後尾のギャレー。
- **浜の戦い**: 青組（攻め手）が小早（こばや）で沖から漕ぎ寄せ、浅瀬→砂浜→逆茂木と乱杭の斜面→高台のコンクリートのトーチカ4基を攻めます。トーチカをすべて制圧すれば勝ち。
- **城の戦い**: 青組が城を守り、橙組が攻めます。大手門（櫓門と狭間のある土塀）→ 二の丸（砂利の中庭）→ 城内（奥御殿：畳の間と襖、いちばん奥が殿の本陣）の三つの区域が、敵が進むにつれて順に開きます。
- **極寒の戦い**: 攻め手として横幅の狭い雪峡谷を縦に進みます。雪に隠れたクレバス（王以外も落ちる）、谷を塞ぐ一本の暗い川（雪の岸と流氷）。寒気と体力減少は橋の無い川に入っているときだけです。凍死では血は出ません。血は傷のときだけ、地面の血糊は小さな跡で、その戦闘のあいだだけ残ります。川岸で待てば、近くの遺体を縦に並べて橋にします。ブリザードの道しるべは垂直に立てた遺体。竹束は矢を受けると壊れます。弓兵は懐刀の突きができ、雪の敵弓兵はツララで突きます。投げナイフはありません。かまくらでしばらく戦闘が無いと、味方全員がおにぎりで少し回復します。本陣では秘書に切腹を命じると、本陣の者だけが腹を切り、一言残します（帝王は切りません）。雪の服装の話も、他の会話と同じように声で返します。被弾すると体が反り、人によっては傷口を押さえます。正面から撃たれると後ろへ、後ろから撃たれると前へ倒れます。倒れる侍女は一枚の写真なので、膝を折る立体の倒れ方そのものにはなりません。
- **山城の戦い**: 高天神にならう山の城を、麓から攻め上ります。味方が二つに分かれ、半分は西峰の大手門、半分は東峰の搦手門を攻めます。各大門には破城隊の丸太（破城槌）がつき、担ぎ手が階段を上って門を突きます。あなたも門を射て、近くなら叩けます。守りは最初から階段の上と、階段の途中の横の足場に立ち、矢とつぶてを落とします（階段の下には立ちません）。押されている峰へ、もう一方の峰から兵が回ります。門の次は二の丸（門は最初から開いている。落とし穴があり、入ると四方から矢）。本丸は滑る石段、トラバサミ、開けると矢の出る扉、針山の床。木の間には梁と柱と横に長い狭間があります。本丸の奥まで入って守りを落とすと勝ちです。

## 城の戦い（`?stage=castle`、v7）
- **大手門**: 閉じた大きな二枚扉。味方の弓兵は塀の **狭間**（細い射ち窓）と櫓門の上から射ます。狭間の弓兵は外からはほとんど当たりません（内からは射ちやすく、外からの矢は細い窓しか通らない）。橙組の **破門隊** が4人で丸太（破城槌）を担いで門へ運び、引いて突く（約2.4秒ごと）。他の近接兵も相手がいなければ門を打ちます。門の上の耐久ゲージが 0 になると扉が内側へ開き、戦いは二の丸へ。
- **二の丸**: 石灯籠・米俵・竹束・井戸が遮蔽物。味方はここへ退いて迎え撃ちます。中央の幟のまわりを橙組が押さえる（または守り手がいなくなる、奥御殿に踏み込まれる）と「二の丸、落ちる！」— 味方は城内へ退きます。
- **城内（奥御殿）**: 畳（黒い縁）、白い襖、柱と長押、格子の欄間、板の天井。広間 → 左右と中の二の間 → 三の間 → 本陣。襖は誰でも開け閉めでき、殿は **E**（スマホは「襖」ボタン、近くで表示）で開け閉め。閉じた襖は通れず矢も止めます。
  - **落とし穴**: いくつかの畳が隠し穴。橙組が踏むと畳が下へ開き、床下へ落ちて脱落します（体は残りません。血や傷はなし）。
  - **伏兵**: 左右の二の間（奥御殿伏兵隊）は閉じた襖の陰で膝をついて待ち、橙組が襖を開けた瞬間（または部屋に踏み込んだ・伏兵が見つかった瞬間）に全員で一斉にかかります。
- **分隊**: 青組＝近衛分隊・槍衆・大手門守備隊・二の丸分隊・奥御殿伏兵隊＋秘書課・医務班。橙組＝破門隊・槍隊・第1攻撃隊・第2攻撃隊・弓隊＋医務班。敵は味方の約1.3倍。
- 殿は奥の本陣から始まり、どの区域へも自由に行けます。切腹など自害の動き・命令はありません。

### v8 の追加（城）
- **梯子で櫓・櫓門へ**: 大手門が破られると、橙組の近接兵が梯子（櫓門は2本）を上り、上にいる味方の弓兵へかかります。
- **二の丸の櫓**: 二の丸の左右に櫓を新設。門が破られると狭間の弓兵が梯子で櫓へ上がり（予備の弓兵2人も櫓の上から）、門から入る敵と矢を射ち合います。橙組が弱ってくると、味方の近接兵・槍兵が「打って出る」（`味方が打って出た！`）。
- **毒煙玉**: 橙組の数人（専門の投げ手、間隔あり）が、櫓・城内など守りの固い場所へ煙玉を投げます。緑がかった灰色の煙が約10秒（屋内は少し長め）漂い、中にいると体力がゆっくり減ります（傷や血の表現はなし）。NPC は「煙が…外へ！」と逃げ出し、近くの襖を開けると早く晴れます。
- **赤い命中演出（全ステージ）**: 命中時に赤い飛沫・ダメージパーティクル・赤いヒットエフェクトを表示します。
- **投げ懐刀（全ステージ）**: 弓兵は近く（約3〜7m）に迫られると懐刀を投げ、落ち着いたら拾いに行きます。殿も懐刀を持っているとき右クリック／F（スマホは「投げる」）で投げられます。投げ槍や破片が飛び散る武器はありません。

### v9 の追加（城）：二の丸の中門
- **中門の門櫓**: 中門の上に足場（前に胸壁、屋根つき）を新設。門が破られると守り手の弓兵4人が上がり、二の丸へ射下ろします。胸壁の陰にしゃがみ、立ち上がって射る（一定の間で必ず顔を出す）。
- **中の塀の狭間**: 中門の左右の塀に狭間（左右4か所ずつ）。守り手の弓兵が二の丸を横から射ます（外からは細く当てにくい）。
- **撃ち合い**: 二の丸の攻め手の弓兵は竹束の陰から門櫓の弓兵を優先して撃ち返します（30m 以内・二の丸に入ってから）。梯子攻め役は二の丸側の梯子（左右2本）から門櫓へ上ります。見通し・矢の弧は上下どちらも同じ判定（胸壁は上半身を残して隠す、見えない壁なし）。
- **突入**: 門櫓と狭間の弓兵が3人以上いる間、攻め手の近接兵は門をくぐらず、二の丸も押さえきれません（制圧6割まで）。減ると「中門の上の守りが薄く…」→ 門を抜けて城内へ。毒煙玉は二の丸の戦いが始まって約45秒後から門櫓へも投げられます。

## 守る／攻める（櫃の戦い・城の戦い、v9。`?mode=atk` / `?mode=def`）
タイトルのステージ選択で「櫃の戦い」「城の戦い」を選ぶと「守る／攻める」を選べます（選択は保存）。
- **攻める**: 青組（殿の側）が攻め手、橙組が守り手。殿の本陣は門の外の陣幕（野営の本陣）で、秘書課・救護班・近衛分隊もそこに控えます。分隊名も入れ替わります（例：城では青組に破門隊・第1/第2攻撃隊・弓隊、橙組に大手門守備隊・二の丸分隊・奥御殿伏兵隊）。
- **城（攻める）**: 破門隊（青組）が丸太で大手門を破る → 二の丸で中門の門櫓・狭間の弓兵と撃ち合い、梯子攻め → 毒煙玉は青組の投げ手だけ（橙組は投げない）→ 奥御殿の襖の伏兵・畳の落とし穴（青組が踏む）→ いちばん奥の間（橙組の本陣）に橙組がいなくなり、味方2人以上（殿は2人分）で6秒押さえれば勝ち（HUD「本陣 奪取 %」）。
- **櫃（攻める）**: 青組が井闌（攻城櫓）の弓兵・梯子攻め役・近接・槍で寄せ、橙組が二基の櫃と武者走りから守ります。両方の櫃から橙組を除き、味方がそばにいる状態を5秒保てば勝ち（HUD「櫃 西○ 東×」）。味方が迫った櫃へは橙組の弓兵は補充されません。櫃の砦の門は開いた門なので破城槌はありません。
- **人数**: 攻め手（青組）は後続が途切れず寄せ（同時に出ている数に上限あり）、守り手は波ごとに決まった数（城は攻め手の約0.85倍、櫃は約1.1倍）。

## 浜の戦い（`?stage=beach`、v8）
- **地形**: 沖 → 浅瀬 → 砂浜 → 逆茂木（枝を外へ向けた柵）と乱杭（打ち込んだ杭）の斜面 → 高台。逆茂木と乱杭は通り道を狭め、足を遅くします（矢や弾はさえぎる）。
- **攻め手（青組）**: 小早1艘に漕ぎ手6〜8人。第n小早隊は低く身をかがめて漕ぎ寄せ、舷（ふなばた）と幟の陰に隠れます。浜に着くと上陸して斜面を上ります。弓兵は舟の上・浜から援護射撃。殿と秘書課は後ろの屋形（小さな屋根つきの小屋）のある舟、近衛分隊はその隣の舟。殿は舟に残っても、上陸しても構いません。分隊：第n小早隊・近衛分隊・秘書課・医務班。
- **守り手（橙組）**: 高台にコンクリートのトーチカ4基（第nトーチカ隊）。中の機関銃は自動で「ダダダダダダダ、ダ…」と区切って撃ち、間をあけて首を振ります（30発ごとに弾込めの休み）。射程は浜と沖の一帯。銃口の閃光・曳光弾・水しぶき・木片・砂煙。当たった娘は白い閃光と砂埃（血はなし）。ほかの守り手は斜面で迎え撃ち・逆襲します。敵は味方の約1.3倍。
- **機関銃を黙らせる**: 銃眼（細い横長の窓）へ矢を射込むか、横・後ろの入口へ回って懐刀で。中に守り手がおらず味方が入ればそのトーチカは制圧（幟が「制圧」に変わる）。
- **舟の上**: 撃たれた娘は舟の中で崩れます（海へは落ちません）。全員倒れた舟は止まって漂います。
- **機関銃の当たり（v9）**: 弾道を体の当たり（縦の円柱）と線で判定。舷より低い弾は舷が止め、屋形（殿の舟の小屋）は大半を防ぎ、幟・櫂にもときどき当たります。撃たれている舟の漕ぎ手はさらに低くかがみますが、全員は隠れきれません。浜・浅瀬では隠れ場所がなく損害が大きめです。
- **殿のひと言**（字幕＋声）: 弾痕だらけで全員倒れた舟を見ると「蜂の巣にされたみたいだな」、黙った機関銃のそばで「…これが機関銃か。恐ろしいな」。

## 軽自動車（平原、v8）
- 本陣の近くに白い軽自動車（右ハンドル）。運転手は白いキャミソールに黒いズボンの侍女。殿は E（スマホは「乗る」）で助手席へ。視点は助手席からの一人称。
- 照準の先の地面を左クリック（スマホは攻撃ボタン）で行き先を指示すると、ほどほどの速さで走ります。前に人がいれば必ず止まる・よけてもらう（車で人を倒すことはありません）。
- 敵の矢は乗っている人にも当たります。運転手が倒れると車はゆっくり止まり、運転手はハンドルに突っ伏します。殿「死者とのドライブかぁ」。殿は降りても、近くの侍女が「私が代わります！」と運転を代わるのを待っても構いません。

## 槍兵（v7）
- 近接兵の約2割が練習用のたんぽ槍（3Dの長い槍を手に持つ）。間合い約2.7m の突き。一直線上 3〜8m に相手がいて間に味方や壁がなければ「突撃！」— まっすぐな一撃はほぼ一撃で倒れ（体力の約9割）、かすめただけなら軽い。
- 懐（約1.2m 以内）に入られると弱い：突きの戻りが遅く、近すぎる突きは外れやすい。下がって間合いを取り直そうとします。機内の狭い通路では、通路に沿った突撃が強い。
- 平原・櫃・城では槍分隊（城は槍衆／槍隊）を組みます。組頭の掛け声「槍衆、構え！」。倒れると槍は手を離れて床に落ちます。当たりの表現は懐刀と同じ（白い閃光と土ぼこりだけ）。

## 近衛分隊（v7・全ステージ）
- 殿のそばにいつも 4〜6 人（懐刀・槍・弓 1〜2）。能力は皆と同じです。本陣では殿のまわりを固め、殿が出ると 2〜4m の輪で一緒に動き、近い敵と殿の間に立ちます。殿の約10m 以内（弓は約22m）に来た敵だけを相手にし、追いかけて離れません。

## 梯子の攻防（櫃の戦い）

## 効果音と笛
- 効果音はすべて WebAudio でその場で合成（音声ファイル不要）。距離で小さく・遠いほどこもり、左右にも振り分けます。
  弓弦の音（自分・周りの弓兵）、近くをかすめる矢の「ひゅっ」、着弾音（地面＝鈍い音＋土埃、竹林・竹束＝乾いた「かつん」、櫃・木の壁・床＝木の「こつん」、体＝布で包んだ矢先の鈍い「ぼすっ」。湿った音・生々しい音はなし）、懐刀の突きの風切り音、足音（土・木の床・はしご）。
- 遠くの合戦の気配：ざわめき、遠くの弓弦の一斉射、遠くの「かかれー！」。太鼓は使いません。
- 本陣のそばに **笛役の娘（味方・非戦闘員、写真の侍女。既定は mob03、`?flute=` で変更可）** が立ち、横笛で行進風の旋律（陽音階）を吹いています。笛の音は彼女の位置から聞こえ、戦闘中は速く力強く、波の合間はゆったりになります。波の始まりの合図も笛です。
- v7：笛の音量を約 -6dB 下げ、声が鳴っている間はさらに約 -6dB 下げます（すばやく下げ、ゆっくり戻す）。
- 機内の戦いでは秘書に「CAさんみたいなことしてよ」と頼めます（機内アナウンスのまね・お飲み物（お茶／お水で体力が少し回復）・安全のしおりの身ぶり・照れて断る、を性格ごとに。奇襲が始まれば途中で打ち切り）。

## 音声
- **音が消えないように（v4）**：声は同時に最大5本までの「席」で鳴らし、満席のときは優先度（会話中・秘書の返事が最優先、次に近いもの）の低い声を止めて席を譲ります。音声の読み込みは同時6本まで（失敗は1回やり直し）。毎秒、音の状態を見回り、止まった音声エンジン（AudioContext）は、キー・タップ・クリック・画面の切り替え（visibilitychange／pageshow／focus）のたびに再開し、下がったままの音量（全体・声）は元に戻します。笛（音楽）は声とは別の経路で、笛役が倒れても遠くの笛として鳴り続け、本陣から離れても小さくなりすぎません。ブラウザの音声合成が固まったときは9秒で打ち切ります。
- 侍女の台詞は **edge-tts（Microsoft ニューラル音声 ja-JP-NanamiNeural）** で事前に生成した mp3（`assets/voices/`、目録 `voices.js`）。性格ごとに話速・高さを控えめに変え、同じ台詞を言い方の違いで3通り用意し、再生時に ±3% の揺らぎを加えています。距離で音量が変わります。
- edge-tts で使える日本語の女性ニューラル音声は Nanami のみのため、声の個性は高さ・速さの違いで付けています。
- 被弾・脱落の台詞は性格ごとに6種類（各3通り）。短い一声（「うっ！」「くっ…！」「きゃっ！」など）＋ひと言だけで、長い悲鳴・うめき・痛がる声は入れていません。
- v5 で台詞を約2.6倍（性格ごとの台詞 90→235）：短い被弾の声（「きゃっ」「いたっ」「えっ、私？」「やられたー…」「無念…」など）、呼びかけ（「右から来てる！」「援護お願い！」「井闌狙って！」「はしご、登ってきてる！」）、仲間が倒れたとき（名前で「〇〇ちゃん！」44人分／「仇とるから！」）、倒したとき（「よっしゃ！」）、隊長の号令、伝令の声。咳き込み・うめき・血を思わせる声は作っていません。全 1243 本、`assets/voices` 約22MB。
- 再生成（このマシンでは venv `/workspace/ttsenv`）: `pip install edge-tts && python3 tools/make_voices.py assets/voices/lines.json`
- 音声ファイルが無い／file:// で開いた場合はブラウザの音声合成（Web Speech）を使います。

## 侍女の見た目（写真のビルボード）とクレジット
- 侍女は全員、元の写真の20人（`assets/mobNN.png` / `archerNN.png`）を **Y 軸だけ回るビルボード** で描き、見る角度で写真を切り替えます：正面／横（右向き。左は反転）／後ろ、移動中は歩きの写真（左右反転を交互にして歩幅を表現＋上下の揺れ）、攻撃中は構えの写真（弓兵＝弓を引く `bow`、近接兵＝突き `stab`）。向きはなめらかに回り、足元に影、縁を少し暗くして厚みを出しています。
- 弓兵は、弓を引く写真（`bow`）がそろった侍女（mob01〜10）と、横・後ろがそろった弓兵の写真の娘から選びます。写真が無い見え方は正面写真で代用します。
- 弓兵の射は弓道の間合い：胴造り（約0.3秒）→ 打起し・引分け（弓を引く写真で少し上がって収まる、約0.5秒）→ 会（冷静・慎重ほど長く 0.6〜1.0秒）→ 離れ → 残心（約0.3秒）。そのぶん物陰で待つ時間を短くし、射る間隔は以前とほぼ同じです（両軍共通）。
- 立っている娘はゆるやかに呼吸して揺れ、秘書はときどき首をかしげたり横を見たりします。靴磨きの間、早瀬ことねは膝をついて靴を磨く写真になります。
- 戦死判定を受けると、横の写真が倒れる方向へ伏せ、そのあと横たわった写真（`down`：頭が左、床の高さから撮影）を体の向きに沿った低いビルボード（高さ約0.5m・長さは身長）で表示します。カメラに向き、頭は実際の頭の側に来るよう左右反転、少し地面に沈め、下に影。櫃の上など真上に近い角度から見ると、同じ写真を地面に置いた絵へなめらかに切り替わります。刺さった矢は胴のあたりに残ります。`down` の無い娘は従来どおり横の写真を伏せます。
- 任意の写真キー：`front_diag`・`back_diag`（斜め前・斜め後ろ。あれば8方向で選び、反対側は反転）、`top`（かなり上から見たとき）、`low`（かなり下から見たとき）。実写が無い角度は、その娘の正面か後ろの写真を一枚だけ少し傾けて作ります。正面の写真と横の写真を一枚に重ねることはしません（弓や体にもう一人が重なって見えていたため）。
- 見え方の写真は `frames/manifest.json`（`{"mob09": {"side": パス, "side_left": パス, "back": …, "walk": …, "bow": …, "stab": …}, "medic": {"front": …, "kneel": …}}`）から `tools/make_frames.py` で作ります（rembg で背景除去、正面写真と同じ縮尺・足元をそろえて `assets/frames/<id>_<frame>.png` と `frames.js`／`frames_data.js` を出力）。`side_left`（左向き）は右向きに反転して使います。
  `/workspace/.rbenv/bin/python3 tools/make_frames.py [--force] [--only mob09,medic]`
- 医療係は専用の写真（正面・膝をつく姿）。`?medic=mob05` などで別の侍女に変更可。
- 刺さった矢は板（ビルボード）に取り付けています。塗料の跡（デカール）は使いません。
- three.js r158（MIT）。照準パネルの顔写真も同じ写真から切り出しています（差し替えは `tools/make_sprites.py`）。

## 歩行サイクル（横から見た連続写真。看護師 `medic` と秘書課 西園寺 すみれ `ojou`）
- 看護師（両軍の看護師が同じ写真）は、歩き・走りを**横から見たとき**、14枚（2歩、同じ絵の重複を除いて7枚）の横向きの歩く写真を、**動いた距離**で進めます。歩調は動きのデータの一歩（`Mo.step` の stepT）にそのまま合わせているので、足音・腰の上下と絵の接地がそろいます。逆向きは左右反転。正面・後ろ・斜めから見たときや、サイクルのない侍女は今までどおりの写真です。写真自体に上下動が入っているので、板の上下動・傾きなどは小さくしています（`CYCLE_DAMP`）。
- 正直な注意：この写真の一歩は身長の約0.26倍（約0.42m）と短く、ゆっくり歩く速さ（約12.5コマ/秒・1周期約1.1秒）向けです。走るときも歩調はモーションに合わせるため、走りでは足が少し滑って見えます（走りのサイクルを足せば直ります）。
- 西園寺 すみれ（`ojou`）：左向きの写真9枚を右向きに反転し、背の高さと腰の位置をそろえて、かかとの接地→荷重→蹴り出し前→つま先離れ（両足が近い）→振り出しの終わり→短い接地前、の6枚（2歩で12コマ）。大股のほぼ同じ写真2枚と、膝を高く上げすぎた写真（下へ曲げると腰がちぎれて不自然なため）は使っていません。抜けている形：**振り出しの途中（遊脚が軸足を追い越す瞬間）**と**蹴り出し直後（後ろ足が地面を離れたばかり）**。この2か所で絵が大きく跳びます。
- 斜め前・斜め後ろ・見上げ・見下ろしの実写（`front_diag`・`back_diag`・`top`・`low`）は `mob01`・`mob02`・`ojou` にあり、いずれも一人の写真です。それ以外の娘（近衛の兵、弓兵、秘書を含む全員）は、足りない角度を正面か後ろの一枚だけから作ります。横顔を正面に重ねて二人にはしません。
- **サイクルの追加方法**：`frames/cycles.json` に `{"<写真のキー>": {"walk_side": {"src": "連番のパス/frame_%02d.png", "n": 枚数, "steps": 何歩分か, "fps": 想定のコマ数, "dir": 1(右向き)/-1, "baseline": 足の接地のy, "contact": 最初の接地のコマ, "stepLen": 一歩の長さ(身長比)}}}` を足し、`python3 tools/make_walkcycle.py` を実行すると、重複を除き、足元をそろえ、正面の写真と同じ背の高さに縮めて `assets/frames/<キー>_walk_side_NN.webp` と目録 `assets/frames/cycles.js`（file:// 用 `cycles_data.js`）を作ります。ゲーム側の変更は不要です。`?cycle=0` で無効。

## 動きのデータ（モーション）で体の重さと厚みを出す（既定で有効・`?motion=0` で無効）
侍女の見た目は今までどおり **写真のビルボードだけ** です。3D の人体モデルは画面に一切描かれません（別人の顔・体は出ません）。実在の人の動きのデータは「動き」と「影・厚み」にだけ使っています。
- **歩き・小走り・走り**：CMU のモーションキャプチャ（実際の人の歩き 07_01／小走り 16_35／走り 09_01）から1周期（左足の接地→次の左足の接地）を切り出し、関節の位置を標準的な女性の体格（身長＝1）に写し直して `lib/motion_data.js`（約60KB）に焼き込みました。実際の移動速度で3つを混ぜ、歩幅から歩調を決めます（足音も左右の接地に合わせて鳴ります）。写真の板には、腰の上下動・左右の揺れ・前後の揺れ、速さに応じた前傾、肩と腰のひねりを移します。性格（好戦的は前傾強め、陽気は弾む、冷静は滑らか…）と身長（背が高いほど歩調がゆっくり）で個人差が出ます。止まると元の呼吸の揺れに戻ります。
- **人の形の影**：関節に沿った円柱と球の「見えない人形」（色も深度も書かない材質）が、歩き・走り・しゃがみ・弓を引く・突くの姿勢で太陽の影だけを落とします（影はプレイヤーの周り約34m）。足元の丸い影は接地の陰りとして薄めに残しています。
- **倒れ方**：Quaternius の倒れる動き（CC0）の腰の高さと上体の角度に沿って、膝が抜けて沈み（脚は地面の下に隠れる）、腰を支点に倒れます（約0.8〜1.0秒）。写真はカメラに向いたまま画面の中で倒れ、手前・奥へ倒れるときは縮んで見えます。倒れ終わると写真が0.3秒で横たわった写真（`down`）に溶け替わります。
- **倒れた体の厚み**：人形は倒れた姿勢のまま残って凸凹した人の形の影を落とし、さらに腰・胸・頭・膝・肘などの柔らかい接地影を重ねます。横たわった写真は地面に沈めず、上から見たときの地面の写真も少し浮かせています。倒れた娘は起き上がりません（戦死判定）。
- 血・傷の表現は今までどおり一切ありません（被弾は白い閃光と砂埃のみ）。
- 切替：`?motion=0`（すべて従来どおり）、`?mshadow=0`（動きは使い、太陽の影だけ止める）、`?mshadow=1`（自動の軽量化をしない）。重い端末では、最初に影の解像度を下げ、それでも遅い（平均 33fps 未満）と自動で太陽の影を止めます（動き・接地影は残ります）。スマホでは影を1フレームおきに更新します。`?motiondbg=1` は開発用（人形を半透明で表示）。
- 再生成：`python3 tools/bake_motion.py`（`lib/mocap_src/*.bvh` と Quaternius の GLB から）。BVH 読み込み `tools/bvh.py`、glTF のアニメ読み込み `tools/gltf_anim.py`。
- **ライセンス**：CMU Graphics Lab Motion Capture Database（mocap.cs.cmu.edu。「複製・改変・再配布は許可なしに可」、製品に含めてよいがデータ自体の販売は不可。The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.）／BVH 変換は github.com/una-dinosauria/cmu-mocap ／Quaternius「Animated Women Pack」（CC0 1.0。動きの関節位置のみ使用、モデル・顔・テクスチャは同梱も表示もしない）。詳細は `lib/mocap_src/LICENSE.txt`。
