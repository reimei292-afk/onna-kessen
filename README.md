# 孤影の弓 ― 模擬戦 ―

ブラウザで遊べる一人称視点のアクションゲーム（オリジナル作品）。ビルドは不要です。
舞台は **模擬戦（演習）** です。武器はすべて先端に塗料が付いた練習用で、当たると塗料の跡が残ります。
青組のあなたは、青組の侍女たち（味方NPC）と一緒に橙組の侍女たちを迎え撃ちます。three.js r158 は `lib/` に同梱しているため、オフラインでも動きます。

## 起動方法
- **かんたん**: `index.html` をブラウザ（Chrome / Edge / Firefox 推奨）で直接開く。
- **ローカルサーバ（推奨）**: このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開く。

「開始」を押すとマウスがロックされ、ゲームが始まります。

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 走る | Shift |
| 跳ぶ | Space |

| 一時停止 | Esc |

## ルール
- **青組（味方）**: 波ごとに自陣側から援軍が合流します（第一波で4人、以後は 2＋波数÷2 人。生存上限は12人）。弓兵が約7割、近接兵が約3割です。
  味方も敵と同じく、性格・竹林を使った遮蔽AI・台詞を持ち、いちばん近い橙組を狙います。橙組は、プレイヤーと青組のうちいちばん近い相手を狙います。
- 頭上の **▼マーカー**（青＝味方、橙＝敵）と、レーダーの色（青＝味方、橙＝敵、黄＝組頭。▲は弓兵）でチームを見分けられます。
- 塗料の色は攻撃した側のチームで決まります（青組の命中＝青、橙組の命中＝橙）。
- **同士討ち**: あなたの矢と懐刀は味方にも当たり、味方も戦死判定になります。その数は HUD の「味方撃破」に記録されます。NPC の矢は味方同士では当たりません。
- 橙組は波（ウェーブ）単位で現れます。種類は **近接兵**（近づいて懐刀で突く。突きのみで、正面の一人にだけ当たる）と **弓兵**（距離を取り、竹林に隠れながら塗料矢を射る）の2つです。
- 第二波からは、体力の多い「組頭」（金色がかった侍女。レーダー上では黄色）が1人加わります。
- **竹林** は矢を止める遮蔽物です。プレイヤーも身を隠せます。
- 命中すると、相手のスプライトの当たった位置に **青い塗料** が付き、矢はそのまま刺さって残ります。白い閃光と砂埃も出ます。
  あなたが被弾した時は、画面に **橙の塗料** が付きます（血の表現はありません）。
- 体力が0になった侍女には **「戦死判定」** が出ます。最後の一言を言って横に倒れ、その後はラウンド終了まで動かず、話さず、その場に残ります。
  性能のため上限は100人で、超えると古い順に消えます。
- 矢は最大40本で、5秒に1本ずつ自然に回復します。矢筒（黄色の輪）を拾うと +6、波を制圧すると +10。
- 兵糧のおにぎり（緑の輪）で体力 +25、波の制圧で +20。
- 頭部に矢が当たると「急所！」となり、威力が2倍になります。
- 照準を侍女に合わせると、名前・性格・兵種・身長が表示されます（倒れた侍女の場合は「戦死判定」と表示）。

## 侍女の個性
侍女は一人ずつ、出現時にプロフィールがランダムに作られます。
- **名前**: 姓と名の組み合わせ（1ラウンドの中で重複しないようにしています）
- **身長**: 150〜175cm。スプライトの大きさに反映されます
- **声**: Web Speech API を使用（ja-JP、女性の声を優先）。性格と身長に応じて、一人ずつピッチと話す速さが変わります
- **性格** は行動と台詞に影響します。台詞は「発見」「攻撃」「被弾」「戦死判定」の4種類です。

| 性格 | 行動 |
|---|---|
| 好戦的 | 足が速く、攻撃の間隔が短い。弓兵は遮蔽に短時間しか留まらず、射るたびに前へ出る。近づかれても下がらない |
| 慎重 | 弓兵は遠い竹林に長く隠れる。近接兵も竹林を経由して近づき、しばらく身を潜めてから攻める |
| 臆病 | 体力が半分になると、いったん退く。狙いは粗い |
| 冷静 | 狙いが非常に正確で、構えの時間はやや長い |
| 陽気 | 平均的。明るい台詞が多い |

## 画像の差し替え・追加
- 近接兵: `assets/mob01.jpg`〜、弓兵: `assets/archer01.jpg`〜（01からの連番。枚数は自由）
  - 弓兵 01〜06 の元画像は `src_archers/archer_ref01..06.jpg`（実写背景）、07〜10 は `src_archers/archer_gen07..10.jpg` です。
- 画像を置き換えたり追加したりした後は、`python3 tools/make_sprites.py` を実行してください（`pip install "rembg[cpu]" pillow` を推奨）。
  rembg（isnet-general-use）で背景を除去して切り抜き、`assets/*.png` と `assets/sprites.js`（埋め込み版。枚数・頭頂位置もここに入ります）を再生成します。
  rembg がない環境では、明るい無地背景向けの色キー処理で代用します。
  PNG を手で直しただけなら `python3 tools/make_sprites.py --no-cut` で `sprites.js` だけを作り直せます。
- http(s) で配信している時は `assets/*.png` を直接読み込みます。`file://` で開いた時はブラウザの WebGL 制限があるため、`sprites.js` の埋め込みデータを使います。

## 技術メモ
- 効果音は WebAudio で生成しています（弦音、遠くの弓、命中、斬撃、被弾、竹に刺さる音など）。音声ファイルは不要です。
- 日本語の音声が OS やブラウザに入っていない場合、台詞は鳴らないか、別の声になります。
- テスト用: `index.html?test=1` で自動プレイ（ポインタロックなし）、`&passive=1` を付けると何もせず立ったままになります。
