# 孤影の弓 ― 模擬戦 ―

ブラウザで遊べる一人称視点のアクションゲーム（オリジナル作品）。ビルドは不要です。
舞台は **模擬戦（演習）** です。武器はすべて練習用（布で包んだたんぽ矢・刃引きの懐刀）です。当たると白い閃光と砂埃が上がるだけで、塗料の跡は付きません（血・赤色の表現はありません）。被弾すると画面の縁が一瞬白く光ります。
青組のあなたは、青組の侍女たち（味方）と一緒に橙組の侍女たちを迎え撃ちます。

公開版: https://reimei292-afk.github.io/onna-kessen/

## 起動方法
- **公開版**: 上の URL をスマホまたは PC のブラウザで開く。
- **ローカルサーバ（推奨）**: このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開く。
- **ファイルを直接開く**: `index.html` を開いても遊べます（写真のフレームは `assets/frames/frames_data.js` の埋め込みデータを使用。収録音声は使えず、ブラウザの音声合成になります）。

タイトル画面でステージ（**平原の戦い** / **櫃の戦い**）を選び、「開始」を押します。

## 操作方法（スマホ・横向き）
左側ドラッグ＝移動スティック、右側ドラッグ＝視点。ボタン：攻撃（弓は長押し→離す、懐刀はタップ）・武器切替・走る（切替式）・跳ぶ・一時停止・頼む（秘書の近くで表示）・**梯子**（梯子の近くで表示。押すと自動で上る／下りる）。縦向きでは「横向きにしてください」と表示され一時停止します。

## ルール
- 波ごとに **橙組と同じ人数の青組** が出ます。両軍とも弓兵が約7割、近接兵（懐刀・突きのみ）が約3割。
- 侍女は一人ずつ名前・身長（150〜175cm）・性格（好戦的／慎重／臆病／冷静／陽気）が違い、行動と台詞が変わります。照準を合わせると顔写真・名前・性格が表示されます。
- 頭上の ▼（青＝味方、橙＝敵）とレーダーの色でチームを見分けます。
- **同士討ち**: あなたの矢と懐刀は味方にも当たります（「味方撃破」に記録）。NPC の矢は味方同士では当たりません。
- **戦死判定**: 体力が 0 になった侍女は倒れるアニメのあと、その場で静止したまま残ります（最大100人。超えると古い順に消えます）。
- 竹林・竹束・木の壁は矢を防ぎます。弓兵は竹束や胸壁の陰でしゃがみ、立ち上がって射ます。

## ステージ
- **平原の戦い**: 竹林が点在する平原。後方に本陣（陣幕）があります。
- **櫃の戦い**: 青組は丸太の砦（門つき）を守ります。二基の櫃（やぐら）と壁の内側の足場に味方の弓兵が陣取り、あなたは左の櫃の上から開始。梯子で上り下りできます。橙組は門の外から竹束を盾に波状に攻めてきます。
- **機内の戦い**: 飛行中の旅客機の機内（曲面の壁と天井、流れる空と峡谷の見える楕円窓、手荷物棚、客室灯）。前から順に、ファーストクラスのラウンジ（殿の席・秘書課が客室乗務員のように控える）、仕切りの高い個室（スイート）、通路の狭い（約0.56m・一人幅）エコノミー、最後尾のギャレー。

## 機内の戦い（`?stage=plane`）
- **始まり**: 静かな機内。味方の娘はエコノミー中心（一部はスイート）に乗客として座り、チャイムと機内の低い音。8〜15秒後、乗客に紛れていた橙組が一斉に武器を取り「奇襲！」。一部は後方ギャレーからも来ます。青組の乗客も席を立って迎え撃ちます（静かな間に攻撃すれば、その場で奇襲が始まります）。
- **分隊**: 青組＝前方客室分隊・後方客室分隊（座席の位置で分け、増援は少ない方へ）＋秘書課・医務班。橙組＝前方奴襲隊・後方奴襲隊＋医務班。増援は後方ギャレーから、味方の増援はラウンジ前方から。
- **狭さ**: 座席は通れず、通路は一人ずつ。座席の列の間にかがんで隠れられ、背もたれは矢を止めます。弓は少なめ（約3割）で、通路沿いの短い距離で射ちます。大半は懐刀。
- **倒れた娘**: 通路では重なって倒れ（段ごとに高さが上がり、上の体を後から描くのでちらつきません）、肘掛け越しに座席へ上体を預けたり、座席の列に倒れて座面に横たわったりします。座ったまま倒れた娘は席で崩れたまま。山の上より手前・先に空きがあればそちらへ崩れて広がります。生きている娘は体をまたいで進むので遅くなり（高い山ほど遅い）、殿も上を越えられます。血や傷は表示しません。
- **医務班** は通路で手当て（青組は前方スイート、橙組はギャレーが拠点）。

## 本陣と秘書課の侍女（白瀬 澄）
本陣（陣幕の内側）にいる間は安全で、敵に狙われません（戦は続きます）。秘書課の侍女（写真の侍女。既定は mob06、`?sec=mob05` などで変更可）に頼めること：
お茶を淹れて（体力回復）／戦況を報告して（味方・敵の数と波）／作戦を相談（味方の方針を攻勢⇔守勢）／肩を揉んで（60秒間、矢の回復が2倍速）／扇であおいで（ひと休み）／矢を補充して／感想を言う（櫃に当たった矢の数・どちらの櫃が押されているか・味方の粘り・敵の弓兵の多さに、戦況に応じて答えます）／**一緒に来て**（弓兵として同行し援護。あなたの攻撃は当たりません。敵に倒されると戦死判定になり、次の波で本陣に戻ります）／**本陣に戻って**。
用件を選ぶとメニューはすぐ閉じ、その様子が画面で見られます（返事は字幕。もう一度 E／「頼む」で開く）。ご飯・感想の小メニューを開くときだけは開いたままです。
どのメニュー・サブメニューにも最後に大きな「戻る」があります（サブメニュー→メインメニュー、メインメニュー→閉じて戦場へ）。
秘書課の侍女・笛役の娘・医療係も、敵にも自分の矢にも当たり、同じ戦死判定を受けます。秘書と笛役は次の波で本陣に戻ります（笛役が倒れている間は笛が止みます）。

## 二人目の秘書（秘書課 早瀬 ことね）
本陣にもう一人、明るい性格の秘書課の侍女がいます（写真は既定で mob07、`?sec2=` で変更可。青組の腕章）。近くで E（スマホは「頼む」）で話しかけます（二人のうち近いほう）。
お茶を淹れて／戦況を報告して／**靴を磨いて**（膝をついて磨き、60秒間 移動が少し速くなる。「ぴかぴかにしておきますね」）／**荷物を持って**（矢筒を持ってついて来る。そばにいる間は矢の上限+10、少しずつ矢を補充）／**本陣に戻って**／戻る（閉じて戦場へ）。
彼女も非戦闘員ですが攻撃の対象になり、戦死判定を受けると次の波で本陣に戻ります。

## 救護班（両軍とも外科医2人＋看護師2人）
青組の本陣と橙組の救護所（「救護」の幟）に、外科医2人（白衣の写真）と看護師2人が控えています（頭上に「救」、組の色の腕章）。
- **倒れた娘（戦死判定）はもう助かりません。** 救護班は倒れた娘を起こしたり手当てしたりしません。手が空いたときに短く確かめに行き（膝をついて約1.3秒）、静かに「…御臨終です」と告げて離れます。
- **負傷**：生きている娘は体力が半分以下になると「負傷」になります（頭上に小さな白い札「負傷」、動きが遅くなる）。約7割は戦うのをやめて自陣の救護所へ下がり、膝をついて待ちます（すぐそばの敵には応戦）。約3割は遅いまま戦い続けますが、救護班が来れば止まって手当てを受けます。
- 救護班は負傷者を最優先します（倒れた娘を確かめに行く途中でも負傷者が出ればそちらへ）。外科医：矢が刺さっていれば「矢が刺さっています、引き抜きますよ」と抜き、手当てして（約4秒）体力を8.5割まで戻し、戦列に返します（「もう大丈夫です」）。看護師：外科医の手当てを手伝い（「先生、お手伝いします」「包帯を巻きますね」「大丈夫、そばにいますからね」。手伝いがいると2割早い）、外科医が皆ふさがっていれば自分で手当てします。近くの救護班の言葉は字幕にも出ます。
- 一人の娘を二人の主治医が取り合うことはありません（主＝medBy、手伝い＝assistBy）。血・傷の表現はありません（包帯の白い布だけ）。
- 非戦闘員ですが攻撃の対象になり、倒されると次の波で持ち場に戻ります。傷・血などの表現は一切ありません。

## 殿が本陣を出ると（戦の最中）
本陣に一度入ってから出ると、秘書たち（白瀬・早瀬・西園寺・桜井・宮下）と救護班の外科医1人・看護師1人が「お待ちください、殿！」「危ないですよ！」と慌てて後を追い、少し後ろ（約3〜6m）について歩きます。ついて来た救護班は殿の近く（22m 以内）で倒れた娘を手当てします。殿が本陣に戻ると皆も持ち場に戻ります。本陣には外科医1人・看護師1人が必ず残ります。
「本陣に戻って」と言われた秘書は追いかけず本陣で待ちます（「一緒に来て」「荷物を持って」で解除）。

## 話している娘が撃たれたら
秘書のメニューを開いている／字幕・声で話している娘が撃たれると、その場で会話を打ち切ります（メニューを閉じ、声と字幕を止め、短い悲鳴だけ）。戦死判定を受けたらもう何も話しません（予約された声も取り消し）。

## お嬢さま秘書（秘書課 西園寺 すみれ、158cm）
王様（プレイヤー、23歳）の遠縁の親戚のお嬢さま。上品で物腰やわらか、少し改まった丁寧語で「王様」と呼びます（「王様、お茶をお持ちしましたわ」「親戚として放っておけませんわ」）。声は他の秘書よりゆっくり・落ち着いた調子。
本陣で話しかけると：お茶を淹れて／戦況を報告して／一緒に来て（戦わずにそばについて歩く）／本陣に戻って／「いつも助かるよ」（控えめに上品にかわす：「まあ、お上手ですこと。でも、褒めても何も出ませんわよ」）。
王様の体力が減って本陣に来ると、先回りしてお茶を出します（+20、50秒に一度）。王様が本陣を出ると他の秘書と一緒に後を追います。戦死判定を受けると次の波で本陣に戻ります。

## 矢の音
- 矢が体に当たる「ズブッ」：鈍い打撃（低い正弦の急降下）＋布越しの柔らかい「どすっ」（こもった雑音）を WebAudio で合成。誰に当たっても位置つき（距離で小さく・左右に振る）で鳴り、自分が射られたときも鳴ります。湿った音・生々しい音は使いません。
- 矢がかすめる「ヒュンッ」：敵味方どちらの矢でも（自分の矢は除く）、カメラから3m以内を当たらずに通り過ぎた瞬間に1回、帯域雑音の中心周波数を高→低へ落とす音（ドップラー風）。近いほど大きく、通った側（左右）へ振ります。同時に鳴るのは4本まで。

## 秘書たちの武器と護身
- 秘書は皆、**腰の帯に鞘に入った懐刀**を差しています（写真の上に小さな鞘を添える。正面・後ろ姿・横で位置を変える）。弓で戦う秘書（白瀬 澄）は**弓を背負い**、弓を引くときは写真の弓になります。お嬢さま（西園寺 すみれ）も懐刀を持っています。
- 本陣では 6.5m 以内、殿について歩いているときは自分か殿の 9m 以内に橙組が来ると、懐刀を抜いて（突くときに抜いた刃が見える）応戦します（弓の秘書は弓で）。相手がいなくなると元の役目に戻ります。

## 三人目・四人目の秘書（秘書課 桜井 ゆかり／宮下 千尋）
本陣で控え、殿が近づくと向き直ってあいさつします。桜井は体力が減っていれば手当て（+15）、宮下は矢が少なければ矢を届けます（+8）。それぞれ45秒に一度。

## 新しい侍女
- 小日向 ひより（152cm・慎重）、氷室 しのぶ（170cm・冷静）、夏目 あかり（162cm・陽気）：両軍の弓兵・近接兵として登場（同時に二人目が出たときは無名）。
- 弓を引く写真だけの6人（arch01〜06）：両軍の弓兵。立ち姿も構えも同じ弓の写真、横向きは左右反転、倒れる時は弓の写真のまま倒れます（横たわった写真なし）。

- v5 の5人（両軍の弓兵・近接兵）：星野 ゆな（166cm・慎重・やわらかく甘い声）、林 玲奈（163cm・好戦的・落ち着いた自信）、桐谷 理紗（160cm・冷静・眼鏡の知的タイプ）、日比野 夏海（165cm・陽気・ごく短い髪で日焼け）、雨宮 小夜（157cm・臆病・サイドの三つ編みで物静か）。声の高さ・速さはそれぞれ別。日比野の歩行写真は左向きだったため、左右反転した写真（`frames/manifest_local.json` で差し替え）で右向きにそろえています。

## 分隊（v5・`?squads=0` で無効）
- 既存の役割（櫃・武者走りの弓兵、門の守り役、梯子攻め、井闌の乗員など）に名前付きの分隊を割り当てます。AI はそのまま。
- 櫃の戦い　青：城門分隊／近接分隊／第1櫃分隊／第2櫃分隊／遊撃弓隊（櫃に上がらず竹束の間を動く弓兵、3人ほど確保）／伝令／秘書課／医務班。橙：井闌隊／はしご隊／第1近接部隊／第2近接部隊／遊撃弓隊／医務班。
- 平原　青：前衛分隊／近接分隊／第1弓分隊／第2弓分隊／遊撃弓隊。橙：第1・第2近接部隊／第1・第2弓分隊／遊撃弓隊（櫃がないので弓分隊）。
- 隊長は能力差なし（同じ数値）。短い号令（「分隊、前へ！」「竹束に隠れて！」「撃てー！」）を出すだけで、交戦していない隊員は隊長（または持ち場）のまわりにゆるく集まります。隊長が倒れると次の者が引き継ぎます。援軍は人数の少ない分隊へ入ります。
- 頭上の小さな名札に「第1櫃分隊 小日向ひより」のように分隊名（隊長は「長」）。秘書の戦況報告に分隊ごとの残り人数、一時停止メニューに分隊の一覧。
- 青組の弓兵は矢に限り（24本）。少なくなると「矢、あと少ししかない！」と声が上がり、**伝令**（本陣から走る足の速い2人）が矢を届けます。用がないときは本陣と分隊の間を伝令として走ります。波が終わると矢は補充されます。
- 修正：橙組の救護班（非戦闘員）が生き残っていると次の波に進まなかった不具合を直しました（波の残り人数に救護班を数えません）。

## 兵数（`?troops=1` で以前の人数）
味方の人数は各波 約1.75倍（第1波 14人、以前 8人）。**敵は味方の約1.3倍**：第1波 14対18、第2波 19対25、第3波 25対33。同時に出ている上限は味方 18（第1波）〜40、敵はその1.3倍（最大 52）。`?troops=1` は以前と同じ 8対8、`?eratio=1.5` などで敵の倍率を変えられます。影を落とす人形は殿から ±37m の範囲だけ描きます。

## 梯子の攻防（櫃の戦い）
- **敵の井闌に上れる**：井闌の後ろの梯子は味方の櫃と同じ操作（前進で上る・後退で下りる、スマホは左スティック）で上れ、高さ8.4mの床に立って戦えます。井闌が動くと上の人も一緒に動きます。
- **味方の近接兵も井闌に上る**：上の弓兵を狙う近接兵は車体を回り込んで後ろの梯子へ行き、上って乗員を突きます。乗員がいなくなると下りてきます。
- **敵が味方の櫃・足場に上ってくる**：砦の中に入った橙組の近接兵（約1/3が「梯子攻め役」）は櫃（6m）や壁の足場（2.9m）の梯子を上り、上の弓兵を襲います。橙組の弓兵の約1/4は空いた射撃位置へ上ります。
- 読みやすさのため：梯子は一人ずつ（下で順番待ち）、上り下りは約1.6m/秒（櫃は約4秒、井闌は約5秒、足場は約2秒）、同じ床へ攻め上がるのは各組2人まで（井闌は3人）、上り始めは3秒以上あけます。梯子の途中では攻撃できず無防備で、矢や下からの突きを受けやすく、戦死判定を受けると梯子の下へ落ちます。下で敵に迫られると上るのをやめて戦います。
- 味方の近接兵は梯子に取り付いた敵を優先して迎え撃ちます。上で相手がいなくなった兵は最寄りの梯子で下ります。

## 近接兵が弓兵を守る（`?screen=0` で以前の動き）
- 近接兵の約45%は「守り役」：近くの味方弓兵と敵の間（弓兵の4.5m前、左右に散開）に立って待ち、敵が10m以内に来たら突きます。
- 近接兵は、味方の弓兵から10m以内に迫った敵の近接兵を優先して迎え撃ちます（距離を0.45倍に見積もる）。前に立つ近接兵より後ろの弓兵を狙うのは後回し（1.3倍）。
- 弓兵は敵の近接兵が8m以内に来ると（好戦的な娘は4m）自分の陣の側へ下がって距離を取り、振り切れなければ至近で射返します。

## 井闌（せいらん）：櫃の戦いの橙組の攻城櫓
門の外から車付きの木の櫓（床の高さ8.4m、味方の櫃は6m）がゆっくり（0.16m/秒）壁へ近づき、壁の11m手前で止まります。第1波は一基、第2波から二基。上には橙組の弓兵2〜4人（波が進むほど多い）。前と左右に胸壁と狭間があり、しゃがむと隠れ、立って射るときに上半身が出ます。上の弓兵を全員倒すと櫓は止まります。空きがあると近くの橙組の弓兵が後ろの梯子から上ってきます。

**お腹減った、ご飯今すぐ作って**（1つの波に1回）：おむすび／味噌汁／お茶漬けから選ぶと、約5秒（進み具合のバーを表示）で本陣の卓に出してくれます。本陣に入ると数秒かけて食べ、体力が少しずつ回復します（+60）。おむすびを食べている間は「手塩にかけたおむすびだね」（T キー／ボタン）と声をかけられます。

## 効果音と笛
- 効果音はすべて WebAudio でその場で合成（音声ファイル不要）。距離で小さく・遠いほどこもり、左右にも振り分けます。
  弓弦の音（自分・周りの弓兵）、近くをかすめる矢の「ひゅっ」、着弾音（地面＝鈍い音＋土埃、竹林・竹束＝乾いた「かつん」、櫃・木の壁・床＝木の「こつん」、体＝布で包んだ矢先の鈍い「ぼすっ」。湿った音・生々しい音はなし）、懐刀の突きの風切り音、足音（土・木の床・はしご）。
- 遠くの合戦の気配：ざわめき、遠くの弓弦の一斉射、遠くの「かかれー！」。太鼓は使いません。
- 本陣のそばに **笛役の娘（味方・非戦闘員、写真の侍女。既定は mob03、`?flute=` で変更可）** が立ち、横笛で行進風の旋律（陽音階）を吹いています。笛の音は彼女の位置から聞こえ、戦闘中は速く力強く、波の合間はゆったりになります。波の始まりの合図も笛です。

## 音声
- **音が消えないように（v4）**：声は同時に最大5本までの「席」で鳴らし、満席のときは優先度（会話中・秘書の返事が最優先、次に近いもの）の低い声を止めて席を譲ります。音声の読み込みは同時6本まで（失敗は1回やり直し）。毎秒、音の状態を見回り、止まった音声エンジン（AudioContext）は、キー・タップ・クリック・画面の切り替え（visibilitychange／pageshow／focus）のたびに再開し、下がったままの音量（全体・声）は元に戻します。笛（音楽）は声とは別の経路で、笛役が倒れても遠くの笛として鳴り続け、本陣から離れても小さくなりすぎません。ブラウザの音声合成が固まったときは9秒で打ち切ります。
- 侍女の台詞は **edge-tts（Microsoft ニューラル音声 ja-JP-NanamiNeural）** で事前に生成した mp3（`assets/voices/`、目録 `voices.js`）。性格ごとに話速・高さを控えめに変え、同じ台詞を言い方の違いで3通り用意し、再生時に ±3% の揺らぎを加えています。距離で音量が変わります。
- edge-tts で使える日本語の女性ニューラル音声は Nanami のみのため、声の個性は高さ・速さの違いで付けています。
- 被弾・脱落の台詞は性格ごとに6種類（各3通り）。短い一声（「うっ！」「くっ…！」「きゃっ！」など）＋ひと言だけで、長い悲鳴・うめき・痛がる声は入れていません。
- v5 で台詞を約2.6倍（性格ごとの台詞 90→235）：短い被弾の声（「きゃっ」「いたっ」「えっ、私？」「やられたー…」「無念…」など）、呼びかけ（「右から来てる！」「援護お願い！」「井闌狙って！」「はしご、登ってきてる！」）、仲間が倒れたとき（名前で「〇〇ちゃん！」44人分／「仇とるから！」）、倒したとき（「よっしゃ！」）、隊長の号令、伝令の声。咳き込み・うめき・血を思わせる声は作っていません。全 1243 本、`assets/voices` 約22MB。
- 再生成（このマシンでは venv `/workspace/ttsenv`）: `pip install edge-tts && python3 tools/make_voices.py assets/voices/lines.json`
- 音声ファイルが無い／file:// で開いた場合はブラウザの音声合成（Web Speech）を使います。

## 侍女の見た目（写真のビルボード）とクレジット
- 侍女は全員、元の写真の20人（`assets/mobNN.png` / `archerNN.png`）を **Y 軸だけ回るビルボード** で描き、見る角度で写真を切り替えます：正面／横（右向き。左は反転）／後ろ、移動中は歩きの写真（左右反転を交互にして歩幅を表現＋上下の揺れ）、攻撃中は構えの写真（弓兵＝弓を引く `bow`、近接兵＝突き `stab`）。向きはなめらかに回り、足元に影、縁を少し暗くして厚みを出しています。
- 弓兵は、弓を引く写真（`bow`）がそろった侍女（mob01〜10）と、横・後ろがそろった弓兵の写真の娘から選びます。写真が無い見え方は正面写真で代用します。
- 弓兵の射は弓道の間合い：胴造り（約0.3秒）→ 打起し・引分け（弓を引く写真で少し上がって収まる、約0.5秒）→ 会（冷静・慎重ほど長く 0.6〜1.0秒）→ 離れ → 残心（約0.3秒）。そのぶん物陰で待つ時間を短くし、射る間隔は以前とほぼ同じです（両軍共通）。
- 立っている娘はゆるやかに呼吸して揺れ、秘書はときどき首をかしげたり横を見たりします。靴磨きの間、早瀬ことねは膝をついて靴を磨く写真になります。
- 戦死判定を受けると、横の写真が倒れる方向へ伏せ、そのあと横たわった写真（`down`：頭が左、床の高さから撮影）を体の向きに沿った低いビルボード（高さ約0.5m・長さは身長）で表示します。カメラに向き、頭は実際の頭の側に来るよう左右反転、少し地面に沈め、下に影。櫃の上など真上に近い角度から見ると、同じ写真を地面に置いた絵へなめらかに切り替わります。刺さった矢は胴のあたりに残ります。`down` の無い娘は従来どおり横の写真を伏せます。
- 任意の写真キー：`front_diag`・`back_diag`（斜め前・斜め後ろ。あれば8方向で選び、反対側は反転。`_left` 付きは左向き）、`top`（かなり上から見たとき）、`low`（かなり下から見たとき）。無ければ従来の正面／横／後ろで代用します。
- 見え方の写真は `frames/manifest.json`（`{"mob09": {"side": パス, "side_left": パス, "back": …, "walk": …, "bow": …, "stab": …}, "medic": {"front": …, "kneel": …}}`）から `tools/make_frames.py` で作ります（rembg で背景除去、正面写真と同じ縮尺・足元をそろえて `assets/frames/<id>_<frame>.png` と `frames.js`／`frames_data.js` を出力）。`side_left`（左向き）は右向きに反転して使います。
  `/workspace/.rbenv/bin/python3 tools/make_frames.py [--force] [--only mob09,medic]`
- 医療係は専用の写真（正面・膝をつく姿）。`?medic=mob05` などで別の侍女に変更可。
- 刺さった矢は板（ビルボード）に取り付けています。塗料の跡（デカール）は使いません。
- three.js r158（MIT）。照準パネルの顔写真も同じ写真から切り出しています（差し替えは `tools/make_sprites.py`）。

## 歩行サイクル（横から見た連続写真。今は看護師 `medic`）
- 看護師（両軍の看護師が同じ写真）は、歩き・走りを**横から見たとき**、14枚（2歩、同じ絵の重複を除いて7枚）の横向きの歩く写真を、**動いた距離**で進めます。歩調は動きのデータの一歩（`Mo.step` の stepT）にそのまま合わせているので、足音・腰の上下と絵の接地がそろいます。逆向きは左右反転。正面・後ろ・斜めから見たときや、サイクルのない侍女は今までどおりの写真です。写真自体に上下動が入っているので、板の上下動・傾きなどは小さくしています（`CYCLE_DAMP`）。
- 正直な注意：この写真の一歩は身長の約0.26倍（約0.42m）と短く、ゆっくり歩く速さ（約12.5コマ/秒・1周期約1.1秒）向けです。走るときも歩調はモーションに合わせるため、走りでは足が少し滑って見えます（走りのサイクルを足せば直ります）。
- **サイクルの追加方法**：`frames/cycles.json` に `{"<写真のキー>": {"walk_side": {"src": "連番のパス/frame_%02d.png", "n": 枚数, "steps": 何歩分か, "fps": 想定のコマ数, "dir": 1(右向き)/-1, "baseline": 足の接地のy, "contact": 最初の接地のコマ, "stepLen": 一歩の長さ(身長比)}}}` を足し、`python3 tools/make_walkcycle.py` を実行すると、重複を除き、足元をそろえ、正面の写真と同じ背の高さに縮めて `assets/frames/<キー>_walk_side_NN.webp` と目録 `assets/frames/cycles.js`（file:// 用 `cycles_data.js`）を作ります。ゲーム側の変更は不要です。`?cycle=0` で無効。

## 動きのデータ（モーション）で体の重さと厚みを出す（既定で有効・`?motion=0` で無効）
侍女の見た目は今までどおり **写真のビルボードだけ** です。3D の人体モデルは画面に一切描かれません（別人の顔・体は出ません）。実在の人の動きのデータは「動き」と「影・厚み」にだけ使っています。
- **歩き・小走り・走り**：CMU のモーションキャプチャ（実際の人の歩き 07_01／小走り 16_35／走り 09_01）から1周期（左足の接地→次の左足の接地）を切り出し、関節の位置を標準的な女性の体格（身長＝1）に写し直して `lib/motion_data.js`（約60KB）に焼き込みました。実際の移動速度で3つを混ぜ、歩幅から歩調を決めます（足音も左右の接地に合わせて鳴ります）。写真の板には、腰の上下動・左右の揺れ・前後の揺れ、速さに応じた前傾、肩と腰のひねりを移します。性格（好戦的は前傾強め、陽気は弾む、冷静は滑らか…）と身長（背が高いほど歩調がゆっくり）で個人差が出ます。止まると元の呼吸の揺れに戻ります。
- **人の形の影**：関節に沿った円柱と球の「見えない人形」（色も深度も書かない材質）が、歩き・走り・しゃがみ・弓を引く・突くの姿勢で太陽の影だけを落とします（影はプレイヤーの周り約34m）。足元の丸い影は接地の陰りとして薄めに残しています。
- **倒れ方**：Quaternius の倒れる動き（CC0）の腰の高さと上体の角度に沿って、膝が抜けて沈み（脚は地面の下に隠れる）、腰を支点に倒れます（約0.8〜1.0秒）。写真はカメラに向いたまま画面の中で倒れ、手前・奥へ倒れるときは縮んで見えます。倒れ終わると写真が0.3秒で横たわった写真（`down`）に溶け替わります。
- **倒れた体の厚み**：人形は倒れた姿勢のまま残って凸凹した人の形の影を落とし、さらに腰・胸・頭・膝・肘などの柔らかい接地影を重ねます。横たわった写真は地面に沈めず、上から見たときの地面の写真も少し浮かせています。倒れた娘は起き上がりません（戦死判定）。
- 血・傷の表現は今までどおり一切ありません（被弾は白い閃光と砂埃のみ）。
- 切替：`?motion=0`（すべて従来どおり）、`?mshadow=0`（動きは使い、太陽の影だけ止める）、`?mshadow=1`（自動の軽量化をしない）。重い端末では、最初に影の解像度を下げ、それでも遅い（平均 33fps 未満）と自動で太陽の影を止めます（動き・接地影は残ります）。スマホでは影を1フレームおきに更新します。`?motiondbg=1` は開発用（人形を半透明で表示）。
- 再生成：`python3 tools/bake_motion.py`（`lib/mocap_src/*.bvh` と Quaternius の GLB から）。BVH 読み込み `tools/bvh.py`、glTF のアニメ読み込み `tools/gltf_anim.py`。
- **ライセンス**：CMU Graphics Lab Motion Capture Database（mocap.cs.cmu.edu。「複製・改変・再配布は許可なしに可」、製品に含めてよいがデータ自体の販売は不可。The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.）／BVH 変換は github.com/una-dinosauria/cmu-mocap ／Quaternius「Animated Women Pack」（CC0 1.0。動きの関節位置のみ使用、モデル・顔・テクスチャは同梱も表示もしない）。詳細は `lib/mocap_src/LICENSE.txt`。
